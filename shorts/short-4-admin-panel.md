## 📝 Description (برای کپی)

```
یه پروژه، چهار تا قابلیت که هرکدوم به‌تنهایی می‌شن یه رزومه 🧠

«بانک سؤال» یه پلتفرم آزمون آنلاین فارسی با UI راست‌به‌چپه:
• بانک سؤال: سه نوع سؤال (چهارگزینه‌ای، صحیح/غلط، تشریحی) + دسته‌بندی، سطح سختی و توضیح پاسخ
• Quiz Builder: انتخاب سؤال، تغییر ترتیب، امتیاز هر سؤال، محدودیت زمانی، حالت تصحیح (AI یا دستی) و انتشار
• صف تصحیح دستی ادمین: پاسخ کاربر در کنار پاسخ مرجع و خروجی AI، با اورراید نمره
• سامانه درخواست کاربر: «این موضوع رو به بانک اضافه کنید» → pending / approved / rejected با یادداشت ادمین
• داشبورد آنالیتیکس: نرخ پاسخ‌های درست هر سؤال، شرکت‌کنندگان و وضعیت آزمون‌ها

🎓 هفته جاری: آموزش کامل ساخت همین پروژه از صفر تا دیپلوی روی Supabase — کانال:
https://www.youtube.com/@sanidev-web

#پروژه_عملی #nextjs #ادمین_پنل #برنامه_نویسی #فرانت_اند
```
